# เอกสารแหล่งข้อมูลน้ำและสภาพแวดล้อม (Water Data Sources Documentation)

**โครงการ:** บ่อดี (BODI) — Smart Aquaculture  
**เป้าหมาย:** ระบบเฝ้าระวังความเสี่ยงน้ำธรรมชาติรอบแปลงเลี้ยงสัตว์น้ำ จ.สมุทรสงคราม (Milestone 1 — Data Discovery & Station Setup)  
**วันที่ตรวจสอบ:** 10 ตุลาคม 2569

---

## 1. บทสรุปการตรวจสอบแหล่งข้อมูล (Source Verification Summary)

| แหล่งข้อมูล (Provider)                           | วัตถุประสงค์                                                     | วิธีการเข้าถึงจริง (Access Method)               | สถานะความพร้อม (Status)              | แผนสำรอง / รูปแบบการใช้งาน (Fallback / Usage)                 |
| ------------------------------------------------ | ---------------------------------------------------------------- | ------------------------------------------------ | ------------------------------------ | ------------------------------------------------------------- |
| **1. Open-Meteo**                                | ปริมาณน้ำฝน (Precipitation), ฝนตกจริง (Rain), อุณหภูมิ, ความชื้น | Live REST API (`api.open-meteo.com/v1/forecast`) | **VERIFIED (ใช้งานจริง)**            | ใช้งานเซิร์ฟเวอร์ดึงข้อมูลสด (Server-side fetch) แบบ Fair-use |
| **2. กรมอุทกศาสตร์ กองทัพเรือ**                  | ตารางมาตราน้ำทำนาย ปากน้ำแม่กลอง (Tide Tables)                   | ดาวน์โหลดตารางประจำปี (PDF / ตารางทางการ)        | **CANDIDATE (พร้อมใช้นำเข้า)**       | นำเข้าตารางทำนายน้ำล่วงหน้ารายปี (Manual / Import Fallback)   |
| **3. Open Government Data (data.go.th)**         | ข้อมูลภัยพิบัติ/ระดับน้ำทำนาย                                    | ดาวน์โหลดชุดข้อมูลสถิติประจำปี                   | **BLOCKED (ไม่เหมาะกับ Live Alert)** | ข้อมูลเป็นชุดสถิติรายปี ไม่มีการอัปเดตแบบ Real-time           |
| **4. กรมควบคุมมลพิษ (IWIS)**                     | คุณภาพน้ำผิวดิน (DO, Salinity, pH) แม่น้ำแม่กลอง                 | เว็บแดชบอร์ด (`iwis.pcd.go.th`)                  | **BLOCKED (ไม่มี Public API)**       | เกษตรกรบันทึกตรวจวัดเองหน้าแปลง (Manual Pond Log)             |
| **5. สสน. / ThaiWater (standard.thaiwater.net)** | ข้อมูลน้ำฝน น้ำท่า มาตรฐานข้อมูลน้ำ                              | มาตรฐานแลกเปลี่ยนข้อมูลภาครัฐ                    | **BLOCKED (ไม่มี Public Open API)**  | อาศัยข้อมูลฝนจาก Open-Meteo และตารางน้ำ ทร. แทน               |

## 2. รายละเอียดผลการตรวจสอบรายแหล่งข้อมูล

### 2.1 Open-Meteo (Weather & Rainfall Data)

- **Source URL:** https://open-meteo.com/en/docs
- **API Endpoint:** `https://api.open-meteo.com/v1/forecast?latitude={lat}&longitude={lng}&current=temperature_2m,relative_humidity_2m,precipitation,rain,weather_code&timezone=Asia%2FBangkok`
- **วิธีการเข้าถึงจริง (Access Method):** HTTPS GET, ส่งผลลัพธ์เป็น JSON ตอบสนองรวดเร็ว (~4ms generation time)
- **การพิสูจน์ตัวตน (Authentication):** ไม่ต้องใช้ API Key สำหรับการใช้งานส่วนบุคคลหรือการทดสอบ (Free tier)
- **เงื่อนไขและลิขสิทธิ์ (Terms / License):**
  - ฟรีสำหรับการใช้งานที่ไม่ใช่เชิงพาณิชย์ (Non-commercial) อัตราการเรียกไม่เกิน 10,000 ครั้ง/วัน, 600 ครั้ง/นาที
  - กำหนดให้ระบุ Attribution: _"Weather data by Open-Meteo.com"_ ภายใต้สัญญาอนุญาต CC BY 4.0
  - หากนำไปใช้ในเชิงพาณิชย์จริงในอนาคต ต้องสมัครแพ็กเกจ Commercial Subscription
- **สถานีอ้างอิงและพิกัดที่ทดสอบ (Verified Coordinates):**
  - ละติจูด: `13.4098`, ลองจิจูด: `99.9965` (พิกัดศูนย์กลางอำเภอเมืองสมุทรสงคราม)
- **พารามิเตอร์และหน่วยวัด:**
  - `precipitation` (ฝนรวม): มิลลิเมตร (mm)
  - `rain` (ปริมาณฝนเฉพาะของเหลว): มิลลิเมตร (mm)
  - `temperature_2m` (อุณหภูมิอากาศ): องศาเซลเซียส (°C)
  - `relative_humidity_2m` (ความชื้นสัมพัทธ์): เปอร์เซ็นต์ (%)
- **พฤติกรรมเวลา (Timestamps):**
  - ระบุ `current.time` ในรูปแบบ ISO-8601 (Local time Asia/Bangkok)
  - ระบบ BODI บันทึกแยกชัดเจนระหว่าง `observedAt` (เวลาตรวจวัดของข้อมูล) และ `fetchedAt` (เวลาที่เซิร์ฟเวอร์ดึงข้อมูล)
- **ความถี่ในการปรับปรุง (Update Frequency):** ทุก 15 นาที สำหรับค่าสังเกตปัจจุบัน
- **ข้อจำกัด (Limitations):** เป็นการตรวจวัดสภาพอากาศและประมาณการเรดาร์ผิวดิน ไม่ได้เป็นเซนเซอร์วัดที่ผิวน้ำในบ่อของเกษตรกรโดยตรง

### 2.2 กรมอุทกศาสตร์ กองทัพเรือ (Royal Thai Navy Hydrographic Department)

- **Source URL:** https://hydro.navy.mi.th/waterlaveltable
- **สถานีทางการ (Official Station):** สถานี **"ปากน้ำแม่กลอง" (Pak Nam Mae Klong - MK)**
  - พิกัดโดยประมาณปากอ่าว: Lat `13.355° N`, Long `100.005° E`
- **เอกสารทางการประจำปี พ.ศ. 2569:**
  - ไฟล์ `MK2026.pdf` (อ้างอิงระดับน้ำลงต่ำที่สุด - Lowest Low Water / LLW)
  - ไฟล์ `MK2026mls.pdf` (อ้างอิงระดับทะเลปานกลาง - Mean Sea Level / MSL)
- **วิธีการเข้าถึงจริง (Access Method):**
  - **ไม่มี Documented Public REST API** สำหรับเชื่อมต่อแบบอัตโนมัติ
  - ให้บริการเป็นเอกสารประกาศรายปี (PDF / ตารางประจำปี) จัดทำโดยการวิเคราะห์ฮาร์โมนิก (Harmonic Analysis) ล่วงหน้า
- **ข้อจำกัดทางอุทกวิทยา (Hydrological Limitations):**
  - ระดับน้ำทำนายที่ปากน้ำแม่กลองเป็นการคำนวณอิทธิพลทางดาราศาสตร์ (แรงดึงดูดดวงจันทร์-ดวงอาทิตย์) เท่านั้น
  - **ไม่ใช่ระดับน้ำจริงในคลองซอยของฟาร์ม:** ระดับน้ำจริงในคลองเชื่อมบ่อขึ้นอยู่กับระยะทางจากปากอ่าว ประตูระบายน้ำคลองชลประทาน มรสุม และน้ำหลากจากต้นน้ำแม่กลอง
- **แนวทางนำไปใช้งาน (Implementation Approach):**
  - จัดเก็บเป็นสถานีอ้างอิงประเภท `CANDIDATE`
  - รองรับการนำเข้าตารางทำนายน้ำขึ้น-น้ำลงสูงสุด/ต่ำสุดประจำวัน (Manual / Batch Import Fallback) เพื่อช่วยเกษตรกรดูกรอบเวลาน้ำขึ้นเพื่อเตรียมตรวจน้ำคลอง

### 2.3 Open Government Data Thailand (data.go.th)

- **URL ตัวเลือก:** https://data.go.th/en/dataset/disaster_2569_145
- **ผลการตรวจสอบ (Verification Result):**
  - ไม่พบการให้บริการ Live streaming หรือ Dynamic API สำหรับระดับน้ำแบบ Real-time
  - ชุดข้อมูลส่วนใหญ่บน data.go.th เป็นชุดข้อมูลเปิดในรูปแบบ CSV/Excel ประจำปีเพื่อการวิจัยสถิติ
  - **สถานะ:** `BLOCKED` สำหรับการแจ้งเตือน Real-time; ไม่นำมาพึ่งพาในระบบเฝ้าระวังอัตโนมัติ

### 2.4 ระบบติดตามคุณภาพน้ำผิวดิน IWIS กรมควบคุมมลพิษ (PCD IWIS)

- **Source URL:** https://iwis.pcd.go.th/
- **ผลการตรวจสอบ (Verification Result):**
  - จุดตรวจวัดและสถานีอัตโนมัติในแม่น้ำแม่กลองได้รับการกำกับเป็นแหล่งน้ำประเภทที่ 3
  - พารามิเตอร์ที่ติดตาม: DO (ออกซิเจนละลายน้ำ), ความเค็ม (Salinity), ความเป็นกรด-ด่าง (pH)
  - **ข้อจำกัดการเข้าถึง:** Endpoint บริการ API หลังบ้าน (เช่น `/pcd-service/...`) ส่งคืนรหัส 404 เมื่อเรียกจากภายนอก หน้าเว็บหลักแสดงผลแบบไดนามิกเฉพาะ Dashboard
  - **สถานะ:** `BLOCKED` สำหรับการดึงข้อมูลผ่าน API โดยตรง
  - **แนวทางปฏิบัติของ BODI:** ห้าม Scraping หน้าเว็บที่เปราะบาง ให้เกษตรกรบันทึกตรวจวัดเองผ่าน PondLog ประจำวัน

### 2.5 สถาบันสารสนเทศทรัพยากรน้ำ (สสน.) / ThaiWater

- **Source URL:** https://standard.thaiwater.net/docs/
- **ผลการตรวจสอบ (Verification Result):**
  - `standard.thaiwater.net` คือเว็บไซต์คู่มือและพจนานุกรมข้อกำหนดมาตรฐานข้อมูลน้ำแห่งชาติ (National Data Standard & Dictionary) เช่น มาตรฐาน A001.1 `/Rainfall`, A002 `/Runoff`
  - ไม่ใช่เซิร์ฟเวอร์เปิดสาธารณะที่อนุญาตให้แอปพลิเคชันภายนอกเรียกดูข้อมูลโดยไม่ต้องมีข้อตกลงความร่วมมือ (MoU) หรือการลงทะเบียนหน่วยงาน
  - เมื่อทดสอบเรียก Request ไปยัง URL มาตรฐาน พบสถานะ 404 (ไม่มีโฮสต์ REST API แบบเปิด)
  - **สถานะ:** `BLOCKED` สำหรับ Direct unauthenticated integration

## 3. หลักการออกแบบสถาปัตยกรรมความปลอดภัยของข้อมูล (Data Principles)

1. **ไม่สมมติหรือสร้างข้อมูลเท็จ (No Hallucinated Data):**
   - พิกัด รหัสสถานี และค่าตรวจวัดทั้งหมดต้องมาจากแหล่งข้อมูลที่มีอยู่จริง หากไม่มีพิกัดฟาร์มแน่นอน ให้กำหนดค่าว่าง (null) และแสดงสถานะว่ายังไม่ระบุ
2. **แยกแยะเวลาชัดเจน (Strict Timestamp Separation):**
   - `observedAt`: เวลาที่ระบุในข้อมูลของแหล่งต้นทาง
   - `fetchedAt`: เวลาที่เซิร์ฟเวอร์ของ BODI บันทึกข้อมูลเข้าสู่ระบบ
3. **สถานะความสดใหม่และคุณภาพ (Freshness & Quality Gating):**
   - ข้อมูลที่มีอายุเกิน 3 ชั่วโมง จะถูกจัดสถานะเป็น `STALE` (ข้อมูลเก่า)
   - ข้อมูลที่ขาดหายไปหรือเก่าเกินกำหนด มีความหมายคือ **"ไม่ทราบสถานะ (UNKNOWN)"** ไม่ใช่ "ปลอดภัย (SAFE)"
   - ไม่อนุญาตให้สร้างการแจ้งเตือนเตือนภัยจากข้อมูลที่ไม่ได้รับการยืนยัน (`CANDIDATE` / `BLOCKED`) หรือข้อมูลที่เก่าเกินเกณฑ์
4. **การสำรองข้อมูลแบบกรอกเอง (Manual Fallback First):**
   - บ่อดีให้ความสำคัญสูงสุดกับการบันทึกจริงหน้าบ่อของเกษตรกร (PondLog) ระบบยังคงใช้งานบันทึกบ่อและจัดการฟาร์มได้สมบูรณ์แม้บริการภายนอกขัดข้องทั้งหมด
